# 🏋️ Gym Management System

A simple and user-friendly **Gym Management System** website developed using **HTML**. This project is designed to provide a clean interface for presenting and managing gym-related information.

## 🚀 Features

* 🏋️ Gym management interface
* 👤 User-friendly design
* 📋 Organized gym-related information
* 💻 Simple and clean layout
* 🌐 Runs directly in a web browser
* 📱 Easy to customize and extend

## 🛠️ Technologies Used

* **HTML5** – Used to build the structure and content of the website
* **CSS** – Used for styling and improving the visual appearance

## 📂 Project Structure

```text
Gym-management-System/
│
├── gym.html
└── README.md
```

## 💻 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Sumanth8970/Gym-management-System.git
```

### 2. Open the project

Navigate to the project folder and open:

```text
gym.html
```

### 3. Run in Browser

Open `gym.html` using any modern web browser such as Chrome, Edge, or Firefox.

## 🎯 Project Objective

The main objective of this project is to create a simple web-based **Gym Management System interface** while practicing fundamental web development concepts and improving HTML and CSS skills.
